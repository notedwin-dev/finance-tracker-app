## Summary

The core domain code is excellent (pure functions, correct logic, well-tested). However, the PR has a **critical write-through gap**: DataProvider handlers compute deltas correctly but never pipe updates to Zustand stores, while pages already read from those stores. Users will see stale balances on every write operation. The PR is not production-ready without fixing this.
